JS Challenges Collection
------------------------
Contains 5 small web apps. Open each HTML file in a browser to test.

Folder structure:
- 1_dynamic_product_list/
    product-list.html, product-list.css, product-list.js
- 2_live_char_counter/
    char-counter.html, char-counter.css, char-counter.js
- 3_multi_step_form/
    multi-step.html, multi-step.css, multi-step.js
- 4_theme_switcher/
    theme-switcher.html, theme-switcher.css, theme-switcher.js
- 5_image_gallery/
    image-gallery.html, image-gallery.css, image-gallery.js

Notes:
- All logic uses core JavaScript (ES6+).
- Test by opening the HTML files in a browser.
